Privacy

Matchburn LUX · effective September 28, 2026

This site collects as little as possible.

What this site does not do

No cookies. No analytics. No tracking pixels. No advertising. Nothing is loaded from anyone else's servers except the links you choose to follow (Instagram, Linktree).

Leaving a note

The note on our postcard is sent by your own email app, addressed to ignite@matchburnlux.com. This site stores nothing you type. We keep the emails we receive only to reply to you, and we never sell or share them.

What the web host keeps

This site is hosted by GitHub Pages. Like every web host, GitHub keeps standard server logs when a page is requested (such as your IP address, the page and the time), under GitHub's privacy statement. We don't receive or use those logs.

The list

Our mailing list isn't open yet. When it opens, this page will say exactly how it works before anyone can sign up.

Questions

Write to ignite@matchburnlux.com. If this page changes, the date above changes with it.
